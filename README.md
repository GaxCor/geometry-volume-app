# geometry-volume-app

Este proyecto es una aplicación sencilla en Python para calcular el volumen de diferentes figuras geométricas en 3D, como boxes, cones, cylinders y spheres.  
Además del cálculo, el proyecto incluye pruebas unitarias para verificar que las funciones se comporten correctamente en distintos escenarios.

## Estructura del proyecto

- `geometry/`: contiene las funciones para calcular el volumen de las figuras (box, cone, cylinder y sphere).
- `tests/`: incluye las pruebas unitarias realizadas con pytest.
- `main.py`: archivo principal para ejecutar el programa.
- `requirements.txt`: archivo con las dependencias del proyecto.

## Cómo ejecutar el programa

Desde la carpeta raíz del proyecto, ejecutar:

```bash
python main.py
```

## Cómo ejecutar las pruebas

Desde la carpeta raíz del proyecto, ejecutar:

```bash
pytest
```

## Dependencias

Para instalar las dependencias necesarias, ejecutar:

```bash
pip install -r requirements.txt
```

La única dependencia externa utilizada en este proyecto es pytest.
